# kb — the support knowledge base

Conventions for pages under `src/routes/kb/` (from the course export).

- Words in the page, logic in `src/lib` (imported as `#lib/…`).
- Frontmatter: `title`, `owner`, `status`, `reviewed`.
- Signed pages: `signature` in frontmatter and `<RenderStamp {signature} />` at the end.

See the course export README for full structure.
